# Predicting-Abnormal-Behavior
A web-based application for detecting and monitoring abnormal human behaviors using computer vision and machine learning techniques. The project provides a Django-based web interface for managing and processing behavior-detection tasks.

#Features


Abnormal behavior detection using computer vision

Django-based web application

User-friendly web interface

Video/image processing support

Detection results and monitoring

Modular project structure

Database integration through Django

Frontend templates, CSS, and JavaScript

Technologies Used

Python

Django

OpenCV

HTML5

SQLite / Django ORM

Machine Learning / Computer Vision
